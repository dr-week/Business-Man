# Coder workflow

1. Read [requirements](REQUIREMENT.md), then relevant module doc.
2. Locate symbols with `rg`; read code before editing.
3. Reuse existing functions/dependencies; smallest complete diff.
4. Preserve unrelated changes, validation, accessibility, provenance.
5. Update owning doc only when contract changes.
6. Report changes, checks performed, blockers; never invent results.

Docs: paths, contracts, commands, limits. No duplicated prose or speculative implementation claims.
